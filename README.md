# WebP Converter

MP4 / MOV をドラッグ&ドロップして、ループする **アニメーション WebP** に変換するデスクトップアプリです。
画質・横幅・フレームレート・トリミング(開始/終了位置)を指定できます。

FFmpeg は同梱されるので、別途インストールする必要はありません。

---

## はじめて動かすまで(所要 10〜15分)

### 1. Node.js を入れる
アプリを動かすのに必要な土台です。まだ入っていなければ、
公式サイト <https://nodejs.org/> から **LTS(推奨版)** をダウンロードして、
画面の指示どおりにインストールしてください。（Windows / Mac どちらも同じ）

インストールできたか確認するには、下の「ターミナル」を開いて次を打ちます:

```
node -v
```

`v20.x.x` のようにバージョンが表示されればOKです。

### 2. ターミナルをこのフォルダで開く

**Windows の場合**
1. この `webp-converter` フォルダをエクスプローラーで開く
2. アドレスバー(上の方の場所が書いてある欄)をクリックして `cmd` と入力し Enter
3. 黒い画面(コマンドプロンプト)がこのフォルダで開きます

**Mac の場合**
1. 「ターミナル」アプリを開く(Spotlight で「ターミナル」と検索)
2. `cd ` と打ってから(半角スペースまで入れる)、`webp-converter` フォルダを
   ウインドウにドラッグ&ドロップして Enter

### 3. 必要な部品をインストールする
ターミナルで次のコマンドを打ちます(初回だけ・数分かかります):

```
npm install
```

### 4. アプリを起動する

```
npm start
```

ウィンドウが立ち上がったら成功です。動画をドロップして試してみてください。

---

## 使い方

1. 動画(MP4 / MOV)をウィンドウにドロップ、またはクリックして選ぶ
2. 設定を調整する
   - **横幅**: 出力の横サイズ。縦は比率を保って自動調整
   - **フレームレート**: 小さくすると軽くなります(WebP は 10〜15fps がおすすめ)
   - **画質**: 0〜100(大きいほどきれい・大きいファイル)
   - **可逆(ロスレス)**: 最高画質。ただしファイルはかなり大きくなります
   - **開始/終了位置**: 秒で指定して一部だけ切り出せます
   - **詳細設定 > 圧縮レベル**: 高いほど小さくなりますが変換が遅くなります
3. 「WebP に変換」を押す
4. 元の動画と同じフォルダに `元の名前.webp` が保存されます

## 配布用アプリ(.exe / .dmg)を作りたいとき

自分や友達がターミナルなしで使えるインストーラーを作れます:

```
npm run dist
```

`dist` フォルダの中に、Windows なら `.exe`、Mac なら `.dmg` ができます。
（注意: Windows 用は Windows で、Mac 用は Mac でビルドするのが基本です）

## ファイルの役割(中身を知りたい人向け)

| ファイル | 役割 |
|----------|------|
| `main.js` | 裏方。ウィンドウを作り、FFmpeg を実行する |
| `preload.js` | 画面と裏方をつなぐ安全な窓口 |
| `index.html` | 画面の見た目 |
| `renderer.js` | 画面の動き(ドロップ受付・設定読み取り・変換呼び出し) |
| `package.json` | 依存する部品とビルド設定 |

---

## うまくいかないときは

- **`npm` が見つからない** → Node.js のインストールが完了していません。手順1をやり直してください。
- **変換でエラーになる** → 対応形式は MP4 / MOV です。壊れた動画や特殊なコーデックだと失敗することがあります。
- **WebP が大きすぎる** → 横幅を小さく、フレームレートを下げる、画質を落とす、のいずれかを試してください。
- **長い動画で時間がかかる** → まずトリミングで短く切り出すのがおすすめです。
